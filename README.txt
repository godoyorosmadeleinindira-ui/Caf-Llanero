ESTRUCTURA
- index.html: contenido y estructura de la página.
- css/estilos.css: estilos, distribución y adaptación a dispositivos.
- js/script.js: menú móvil y validación del formulario.
- img/: imágenes de la galería.

PARA PROBAR
1. Extraer el ZIP.
2. Abrir la carpeta en Visual Studio Code.
3. Abrir index.html con Live Server o directamente en el navegador.
4. Probar todos los enlaces del menú.
5. Probar el formulario con campos vacíos y con un correo inválido.
6. Reducir el tamaño de la ventana para comprobar el diseño responsive.
